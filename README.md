# Sysmon-Linux-Integration-For-Splunk
This Splunk add-on enables Sysmon Linux integration with your Splunk instance by providing improved field extraction and normalization. It is intended as a replacement for the official Splunk Add-on for Linux available in the Splunk App Center, which is no longer maintained and does not support newer versions of Sysmon.

The current version was developed for personal use and lab environments. It has been tested with Sysmon version 1.40. and [ELRS-Sysmon](https://github.com/NightAsylum/ELRS-Sysmon) ruleset.

> **Warning:** This app was AI-generated; therefore, please test it in a lab environment before deploying it to production.
